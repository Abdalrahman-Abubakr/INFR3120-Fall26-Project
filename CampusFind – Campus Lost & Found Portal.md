# **CampusFind – Campus Lost & Found Portal**

CampusFind is a web application which allows students and staff of Ontario Tech University to track and report the lost items.It allows users to register their lost things or things they have found, thus making the process of reuniting things with its owner easier. This way, the information can be stored in one place, eliminating the hassle of different social media postings and messages.

The application will include a landing page that displays recent lost and found reports in an organized table.Users will be able to create a new report by entering details such as the item name, category, description, location, date, and whether the item was lost or found. Each report will also have a status to indicate whether the item is still available or has been claimed. The application will use a database to store reports so that submitted information can be retrieved and displayed.

The first release will focus on the main features of the application: a functional landing page, a form for creating lost or found reports, and a table displaying submitted reports.The project has been developed using Node.js, Express.js, EJS, and MongoDB, with Bootstrap used to help create the user interface. Future improvements could include searching and filtering reports, user accounts, and a more complete item-claiming process.
